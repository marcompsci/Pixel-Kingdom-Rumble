# App Review notes (Pixel Kingdom Rumble 1.0)

Paste into App Store Connect > App Review Information > Notes:

```
Pixel Kingdom Rumble is an original pixel-art platformer and arena brawler. No account or sign-in is needed, and the app collects no data.

How to try each mode (all free except Shadow Contracts):
- Story Quest: Main Menu > STORY QUEST > pick a hero > pick a level. Every level is open from the start. Use the < > buttons for World 3.
- Arena Clash: Main Menu > ARENA CLASH. Tap START for a match vs CPU fighters. DAILY RUMBLE is on the same screen.
- Versus: Main Menu > VERSUS · 1 ON 1, against the CPU.
- Couch 2P: Arena Clash > PLAYERS: 2. With no controller the screen splits into two touch halves.

In-app purchase "Shadow Contracts" ($3.99, non-consumable): Main Menu > SHADOW CONTRACTS > UNLOCK ALL CONTRACTS. It unlocks the stealth contract board; the first contract is free to play before buying. RESTORE PURCHASE is on the same screen.

Star Shards are earned in play only and are never sold. They buy cosmetic palettes and Story-only upgrades.

Game Center: an optional leaderboard (Shadow Contracts total, Rumble Rating) and achievements.
Controls: on-screen touch controls (movable in Pause > SETTINGS > EDIT CONTROL LAYOUT) or any MFi/Bluetooth game controller.
```
