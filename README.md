# Pixel Kingdom Rumble (working title)

An original 2D pixel-art action platformer + arena brawler for iPhone, built in Unity 6 LTS (2D URP, C#).

> All names, characters, art, audio and levels are original or placeholder. See [Docs/NAMING.md](Docs/NAMING.md)
> for the rename registry and [Docs/CREDITS_AND_LICENSES.md](Docs/CREDITS_AND_LICENSES.md) for asset sources.

**Current status:** Phase 1, increment 1 of 8. See [Docs/STATUS.md](Docs/STATUS.md) for exactly what is built,
what was tested, and what is not verified yet.

---

## Quick start

1. Follow [Docs/SETUP.md](Docs/SETUP.md) once to create the Unity project around this repo.
2. In Unity: **PKR > Configure iOS Player Settings**.
3. **Window > General > Test Runner > EditMode > Run All**.

## Controls (planned for increment 2)

Landscape. Left side: floating virtual joystick (move / aim). Right side: **Jump**, **Attack**, **Special**, **Dodge**.
Jump has a 0.12 s buffer and 0.1 s coyote time. Layout, scale, haptics, volumes, screen shake and high-contrast UI
are all in Settings. For Editor testing, keyboard/gamepad bindings will be included.

## Tests

| Suite | Location | How to run |
|---|---|---|
| EditMode (43 tests) | `Assets/_Project/Tests/EditMode` | Unity: Test Runner > EditMode > Run All |
| Same tests, no Unity | `DotnetTests/` | `cd DotnetTests && dotnet run` (needs .NET 8 SDK) |

`DotnetTests` compiles the Core scripts and the EditMode tests with a tiny NUnit-compatible shim, so the rules
can be checked on any machine or CI. It covers combat math, Guard Pips, jump assist, save/settings repair,
economy and arena match rules.

## Design notes

- **Guard Pips** (original arena system): 3 pips per fighter; hits remove pips; at 0 the fighter is *Exposed* and
  the next heavy hit launches hard. Pips regenerate after 3 s without being hit. The hit that breaks the last pip
  does not itself get the Exposed bonus.
- Story Quest uses HP and armor instead of pips.
- Economy is cosmetic-only by design.
